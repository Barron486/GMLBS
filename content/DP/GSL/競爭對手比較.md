# CytoInsight GSL 方案比較原則

> [!WARNING] 尚待競品一手來源逐項驗證
> 本頁只提供比較框架，不對未取得最新版官方文件的競品作法規、效能或市場地位判斷。

## 建議比較維度

| 維度       | CytoInsight GSL 已確認能力       | 比較時應索取的證據                 |
| ---------- | -------------------------------- | ---------------------------------- |
| 用途       | RUO                              | 各地正式標示與 IFU                 |
| 影像模式   | 明視野與螢光                     | 支援的樣本、相機與擷取模式         |
| 自動送片   | GSL 10／120                      | 實際容量與連續作業限制             |
| 自動化     | 條碼模板、自動點油（依配置）     | 標準／選配界線與驗收方法           |
| 分析       | 核型、FISH spot counting、M-FISH | 軟體版本、模組授權與輸出格式       |
| 資安與整合 | 依正式系統配置                   | 作業系統、帳號權限、備份與介面文件 |

不得使用「他牌無法臨床」「唯一 IVD」「全球黃金標準」等未經同版本、同地區一手資料支持的宣稱。
