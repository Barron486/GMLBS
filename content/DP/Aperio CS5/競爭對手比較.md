# 比較評估框架

本頁不再使用「攻擊點」、「阻擋競品」或未具完整市場證據的「獨家」說法。建議以實機與文件比較：

| 評估面向       | 可驗收問題                                                                            |
| -------------- | ------------------------------------------------------------------------------------- |
| 法規用途       | 比較的確切型號在使用地區是 RUO 或 IVD？核准用途與搭配元件為何？                       |
| 載片與玻片尺寸 | 標準玻片與 2×3 英吋玻片各可裝載幾片？更換托盤需要多少操作？                           |
| 掃描品質       | 在相同玻片、倍率與掃描區域下，首次成功率、重掃率與偽影如何？                          |
| 效能           | 以相同起訖點量測單片可用時間與批次完成時間                                            |
| 特殊模式       | 手動掃描、Z-stack、焦點控制及大玻片功能是否為標配或選配？                             |
| 互通性         | 實際輸出檔案能否被指定的 IMS／viewer 讀取；DICOM conformance statement 是否符合需求？ |
| 維運           | 比較保固、回應時間、耗材、校正、資安更新與總持有成本                                  |

Leica 公開資料可確認 CS5／CS5 DX 具有五片標準玻片或兩片大玻片托盤、20×／40×、手動掃描、Z-stack，以及 SVS／DICOM 輸出。這些應稱為 Leica 產品特點，而非未經證明的市場獨家優勢。
