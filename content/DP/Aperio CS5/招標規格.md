# 建議功能／效益規格

下列內容為需求草案，應加入「或同等品」，並由採購單位依實際流程設定驗收門檻。

| 可量測需求                                                                        | 建議驗收方式                           |
| --------------------------------------------------------------------------------- | -------------------------------------- |
| 可批次裝載至少 5 張標準 1×3 英吋玻片，或支援 2×3 英吋大玻片                       | 現場以兩種托盤與測試玻片操作           |
| 支援 20× 與 40× 掃描，20× 取樣解析度不劣於 0.50 µm/pixel                          | 查核原廠規格並以測試影像確認 metadata  |
| 支援手動設定掃描區域、焦點與焦平面                                                | 現場操作驗收                           |
| 支援 Z-stack                                                                      | 以厚切片或測試玻片產出多焦平面影像     |
| 可輸出 SVS 及 DICOM，或提供同等開放介接能力                                       | 以實際檔案匯入指定檢視／管理系統       |
| 20×、15 mm × 15 mm 區域的單片結果於約 50 秒可供使用，或符合採購單位設定的等效效能 | 使用一致玻片、區域與計時起訖點重複測試 |
